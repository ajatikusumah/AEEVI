# AEEVI organisation website

Website profil organisasi AEEVI menggunakan HTML, CSS, dan JavaScript tanpa framework. Versi ini menggunakan beberapa halaman dengan navigasi bersama.

## Halaman

Beranda, Tentang AEEVI, Kegiatan & Berita, Continuing Professional Development (CPD), Publikasi, Keanggotaan, dan Kontak.

## Menjalankan secara lokal

Buka `index.html` langsung di browser, atau jalankan server lokal dari folder ini:

```bash
python3 -m http.server 8080
```

Kemudian buka `http://localhost:8080`.

## Deployment

Website dipublikasikan melalui GitHub Pages dari branch `main` dan menggunakan domain kustom `aeevi.org`.
